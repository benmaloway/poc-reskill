#POC 1 — CRUD Application (Foundation)
Context: discovering Angular after TypeScript.
Objective: understand the fundamentals of modern frontend development and create a simple management application (e.g., task manager or contacts list).

The developer must build an Angular app to manage a task list.

##To build:
A main page with a form to add a task and a list displaying tasks
Each task must include: title, description, status (todo / done)
Implement actions: Add, Edit, Delete, Mark as complete

Technical context: data stored locally (localStorage or Angular service) — no external API.

Expected deliverables: 1 functional application with simple UI, 3–4 minimum components (list, form, item…), use of an Angular service.

Estimated effort: 2–3 days

Technical challenges: creating components, using forms (input, submit), implementing full CRUD, simple state management (services).

What this builds: understanding of Angular basics, clear picture of how a modern web app works, first autonomy in Angular.
